# Shortcuts (VS Code + Emmet + JavaScript)

## 1. Emmet Shortcut (HTML Boilerplate)
- `!` + `Tab` — default HTML boilerplate code likh deta hai (doctype, html, head, body tags).
- `div.container` + `Tab` — `<div class="container"></div>` bana deta hai.
- `div#app` + `Tab` — `<div id="app"></div>` bana deta hai.
- `ul>li*5` + `Tab` — ek `ul` ke andar 5 `li` items bana deta hai.
- `p{Hello}` + `Tab` — `<p>Hello</p>` bana deta hai.

## 7. JavaScript Code Shortcuts (Important Syntax Yaad Rakhne Ke Liye)
| Shortcut/Syntax | Kaam |
|-----------------|------|
| `console.log()` | Value ko console me print karna |
| `===` | Strict equality check (type + value dono) |
| `?.` | Optional chaining — agar object/property undefined ho to error nahi aata |
| `??` | Nullish coalescing — left side `null`/`undefined` ho to right wali value use hoti hai |
| `...` | Spread/rest operator — array/object expand ya collect karna |
| `=>` | Arrow function likhna |
| `` `${variable}` `` | Template string me variable insert karna |
| `&&` | Short-circuit — pehla falsy aaya to wahi return, warna dusra |
| `\|\|` | Short-circuit — pehla truthy aaya to wahi return, warna dusra |
